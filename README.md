# Sitio web de O-Isym

Página oficial de descargas: https://cuelorubik.github.io/O-Isym/

GitHub Pages publica la raíz de la rama `oisym-website`. `index.html` contiene todo el diseño y consulta las publicaciones estables de GitHub para mostrar los instaladores más recientes y las versiones anteriores. Los botones enlazan directamente a los instaladores de Releases.

Para publicar una nueva versión, crea una release estable y adjunta los instaladores `.dmg`, `.exe`, `.msi` o `.apk`. Se elige la publicación más reciente por fecha para admitir el cambio de numeración de 5.0.0 a 1.1.0. Las descargas conocidas permanecen disponibles si falla la API.

Esta rama contiene únicamente el sitio web; el código de las aplicaciones se mantiene en sus respectivas ramas.
